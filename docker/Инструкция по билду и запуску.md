## Сборка образа и запуск тестов в Docker

### 1. Сборка образа

Из **корня проекта** выполнить в PowerShell:

```powershell
docker build -f docker/Dockerfile -t autotests-python:local .
```

- `-f docker/Dockerfile`: путь к Dockerfile.
- `-t autotests-python:local`: имя и тег образа.
- `.` (точка в конце): build context, то есть корень проекта.

### 2. Что происходит при сборке

Docker берёт Dockerfile по пути `docker/Dockerfile` и автоматически применяет к нему ignore-файл `docker/Dockerfile.dockerignore`, лежащий рядом.

> Имя ignore-файла должно в точности совпадать с именем Dockerfile плюс `.dockerignore`. Если назвать его иначе, сборка всё равно запустится, но файл будет проигнорирован: Docker возьмёт общий `.dockerignore` из корня проекта, а если его нет, в образ попадёт всё лишнее (`.venv`, `.git`, `.env` и т. д.).

### 3. Запуск тестов

После появления образа:

```powershell
docker run --rm autotests-python:local
```

- Дополнительных команд нет, поэтому запустится команда по умолчанию из Dockerfile (`CMD`): `uv run pytest`.
- `--rm` удаляет контейнер после завершения, чтобы не копировались остановленные контейнеры.
